# Nauka Gita i GitHuba

Repozytorium powstało podczas nauki podstaw systemu kontroli wersji Git.

## Przećwiczone zagadnienia

- tworzenie commitów,
- praca na gałęziach,
- scalanie gałęzi za pomocą `git merge`,
- połączenie repozytorium lokalnego z GitHubem,
- wysyłanie zmian poleceniem `git push`.
